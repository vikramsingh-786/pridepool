# pridepool

Lemonn × Booming Bulls — **The Pride Pool**, a ₹1 Crore Brokerage Credits Pool campaign page.

Built with Next.js 16, React 19 and Tailwind CSS 4.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Routes

- `/` — campaign landing page
- `/terms-and-conditions` — draft campaign terms

## Before launch

- Set `JOIN_HREF` in `app/_lib/links.ts` to the approved campaign link.
- Replace the fictional leaderboard data in `app/_mock/leaderboard.ts`.
- Set `NEXT_PUBLIC_SITE_URL` to the production domain.
- Get legal sign-off on the terms, FAQs and disclaimers.
